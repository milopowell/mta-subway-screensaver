# Subway screensaver (Swift)

The native macOS app and screensaver. The project overview, data flow, settings and known issues are in the [main README](../README.md); this file covers only the Swift code.

The app reads the two files the notebook exports in §8 of `subway_pipeline.ipynb`: `../export/map_black.pdf` and `../export/network.json`. Both are copied into the app and the screensaver at build time, so **rebuild after re-running the export**.

## Layout

| Folder | Built into | Contents |
|---|---|---|
| `Shared/` | both targets | Everything below |
| `PreviewApp/` | SubwayPreview | A normal Mac app that shows `SubwayView` in a window, for development, plus the command-line test options |
| `Saver/` | SubwaySaver | `SubwaySaverView`, the `.saver` entry point: hosts `SubwayView`, provides the Options sheet, stops on `willstop`; `thumbnail.png` for System Settings |
| `../export/` | both targets | The notebook's exported map and network data (bundled as resources) |

The project uses Xcode's folder-synced groups, so a file added to one of these folders joins the matching target(s) automatically. `SubwaySaver.xcodeproj` is generated by `../tools/gen_xcodeproj.py`; regenerate it rather than editing it by hand.

### Shared code

| File | Role |
|---|---|
| `SubwayView.swift` | Lays out the map panels and the next-train board (split or close-up layout). Downloads feeds every 30 s and updates trains every second |
| `MapPanel.swift` | One view of the map: the map bitmap, its train dots and an optional dashed outline |
| `MapDocument.swift` | Renders a region of the map PDF to a bitmap |
| `Viewport.swift` | Fits a map region to a panel's shape |
| `SubwayNetwork.swift` | Reads `network.json` |
| `FeedClient.swift` | Downloads and decodes the 8 live feeds in parallel; `FeedCache` holds each feed's last good download when one fails; `FeedHub` shares one download loop among all views |
| `gtfs-realtime.pb.swift` | Generated feed decoder (do not edit) |
| `Locator.swift` | Places trains: an exact port of the notebook's `locate_from_export` (hops follow the exported `hop_paths`), plus each train's timeline of hops (`legs`) |
| `MotionPlanner.swift` | Turns timelines into motion: when each train stops, glides, waits or catches up |
| `TrainLayers.swift` | Draws the dots and runs the glide animations (Core Animation) |
| `TripHistory.swift` | Records when each train actually reached and left each station, from successive downloads |
| `TimeLapse.swift` | Replays that history at 20 times speed in a loop (same commands as MotionPlanner): a backup when live data is unavailable |
| `Polyline.swift` | Geometry along a track line |
| `NextTrains.swift` | The next-train board: arrivals per home station, uptown and downtown |
| `StationPicker.swift` | The home-station picker: your stations (reorder, remove), search, browse by line, stations by borough (preview app only: a screensaver cannot be clicked) |
| `RouteSymbols.swift` | Route symbols (colored circles, diamonds for express variants), shared by the picker |
| `SubwaySettings.swift` | Saved choices: home stations (up to 4), layout, magnification |

## Building and running

Build by **scheme** so the SwiftProtobuf package is built too (a `-target` build fails). Use Release to measure performance.

```bash
cd ~/mta-screensaver/swift && xcodebuild -project SubwaySaver.xcodeproj -scheme SubwayPreview -configuration Release -destination 'platform=macOS' -derivedDataPath build/DerivedData -clonedSourcePackagesDirPath build/SourcePackages build
```

```bash
open ~/mta-screensaver/swift/build/DerivedData/Build/Products/Release/SubwayPreview.app
```

In Xcode: open `SubwaySaver.xcodeproj`, pick the SubwayPreview scheme and press Command-R.

Preview app options (run the executable inside the app directly):

- `--fullscreen`: start in full screen (Control-Command-F toggles it, Command-Q quits)
- `--snapshot out.png [--width 1512 --height 982]`: render the view to a PNG and quit, without a window
- `--home ID,ID`, `--layout split|closeUp` and `--magnification M`: home stations, layout and magnification for a snapshot only
- `--dump-placements out.json`: write every trip's placement (feed, trip_id, x, y, how) and quit
- train data for those two: `--live` (download now), or `--feeds-dir DIR --now UNIXTIME` (saved feeds `DIR/<feed>.pb`)
- `--plan-report [--seconds 90]`: run the motion planner on live data and report how trains move
- `--time-lapse`: force the time-lapse (normally a backup when live data is unavailable)
- `--path-report out`: check the track every hop follows; writes `out.png`
- `--picker-snapshot out.png [--home IDs --line ROUTE]`: render the home-station picker
- `--time-lapse-report [--record 420 --seconds 60]`: record live history, replay it, and check the replay is smooth
- `--timing-report [--seconds 180]`: compare the dots' station arrivals and departures with the real trains
- `--simulate-outage FEED[,FEED...]` or `--simulate-outage all`: treat those feeds as failed after the first download (in the window, in `--plan-report`, and in `--snapshot`)

`build/` holds build output and can be deleted at any time.

## Installing the screensaver

`zsh ../tools/install_saver.sh` builds and installs it in `~/Library/Screen Savers`; `../tools/test_saver.swift` tests the built bundle without installing it (see the main README).

## Regenerating the feed decoder

`Shared/gtfs-realtime.pb.swift` is generated from the same schema the notebook's Python bindings use, saved as `../tools/gtfs-realtime.desc`. Install the tools with `brew install protobuf swift-protobuf`, then run `protoc` with `--swift_out`. The SwiftProtobuf package version in the project must be at least the `protoc-gen-swift` version that generated the file (currently 1.39.0).

## Sharing
